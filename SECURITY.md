# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ObiDoge (OBD), please report it responsibly.

**Do NOT open a public GitHub issue for security-sensitive bugs.**

Instead, contact the development team privately:

- **Email:** security@obidoge.xyz

Please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Affected version(s)
- Any relevant logs or proof-of-concept code

We will acknowledge receipt and investigate promptly.

## Supported Versions

Only the latest released version is supported for security updates.

Current release:
- **v0.16.4** (mainnet)
